# 🎨 Member 4: The Frontend Visionary
**Mission:** Immersive 3D Experience & Dynamic Rendering

## 📋 Overview
The Frontend Visionary builds the interface that wows the user. This role ensures that the complex AI logic behind the scenes is presented as a premium, state-of-the-art storefront.

## 🚀 Implementation Strategy
- **Design Language:** Modern dark mode, mesh gradients, and Inter typography for a high-end feel.
- **Two-Page Architecture:**
    - `index.html`: The high-conversion Generator landing page.
    - `store.html`: The dedicated, clean output storefront.
- **UX Flow:** Smooth transitions from "Input" to "Generating" to "Launch" using automatic redirection and smooth scrolling.
- **Dynamic Assets:** Renders products in a responsive CSS Grid with glowing discount badges and AI-generated photography.

## 📂 Key Outputs
- `src/frontend/index.html` & `store.html`: The HTML structure.
- `src/frontend/style.css`: The visual design system.
- `src/frontend/script.js`: The frontend logic and API integration.
